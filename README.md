# 摊位账本 · 公开下载

商品、库存、套装销售与财务管理的小型网站。

[下载最新版本](https://github.com/Senyo1547/ba-stall-pos-releases/releases/latest) · [直接下载 v2.0.0](https://github.com/Senyo1547/ba-stall-pos-releases/releases/download/v2.0.0/stall-studio-v2.0.0.zip)

解压后打开 `index.html` 可单机使用。多人同步请按包内 README 启动共享服务，需要 Python 3.10+。

支持商品图片、自由定价与库存、组合套装、人工确认收款、取消/退款、支出、备份和旧版账本导入。个人收款码需人工核实到账，不会自动读取支付账户余额。

本仓库用于公开分发下载包与使用说明，不包含原开发仓库的提交历史或实际经营数据。网站运行需要的 HTML、JavaScript 和服务文件包含在下载包内。
